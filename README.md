
# 🌱 Greenix
### Gamified Eco-Learning Platform for Sustainable Awareness

**Greenix** is an interactive web platform designed to promote **environmental awareness through gamification and AI assistance**.

The application combines **educational content, interactive mini-games, and an AI-powered eco assistant** to help users learn sustainable habits in an engaging and practical way.

Instead of passive learning, Greenix encourages users to **learn sustainability concepts by interacting, playing, and exploring eco-friendly actions.**

# 🌍 Overview

Greenix is built to **educate and inspire users to protect the environment** through engaging digital experiences.

The platform provides:

* **Gamified environmental education**
* **AI-powered eco assistant**
* **Interactive sustainability challenges**
* **Modern responsive UI**

Users can **play educational games, test their environmental knowledge, and receive eco-friendly guidance from AI**.

---

# ❗ Problem Statement

Environmental awareness platforms often struggle with **low engagement and passive learning experiences**.

Common issues include:

* Lack of interactive content
* Limited user engagement
* Difficulty forming sustainable habits
* Traditional education methods that fail to retain user attention

As a result, many individuals **want to help the environment but lack motivation and practical knowledge.**

---

# 💡 Solution

Greenix addresses this challenge by introducing a **gamified sustainability learning platform**.

The platform transforms environmental education into **interactive activities**, including:

* Eco-based games
* Sustainability quizzes
* AI-driven eco guidance
* Educational challenges

By combining **technology, AI, and gamification**, Greenix makes environmental learning **engaging, practical, and memorable**.

---

# ✨ Key Features

## 🎮 Gamified Environmental Learning

Greenix includes multiple **eco-themed games and interactive activities** that teach sustainability concepts in a fun way.

Examples include:

**Eco Quiz**

* Interactive quizzes about sustainability
* Tests environmental awareness
* Immediate feedback and learning

**Water Savior**

* Teaches water conservation techniques
* Simulated decision-making gameplay
* Reinforces sustainable water usage habits

More eco-based games are planned to expand the learning experience.

---

## 🤖 AI EcoBot Assistant

Greenix features an **AI-powered EcoBot** built using **Gemini 3.5**.

The AI assistant helps users:

* Ask environmental questions
* Learn eco-friendly habits
* Get sustainability suggestions
* Understand environmental issues in simple language

This provides **personalized learning support** for users.

---

## 🎨 Modern User Interface

The platform uses modern UI technologies to create a **smooth and engaging experience**.

Features include:

* Responsive design
* Animated interactions
* Clean minimal interface
* Component-based UI structure

---

## 📊 Interactive Learning Experience

Instead of reading static articles, users learn through:

* Gameplay
* Quizzes
* Interactive prompts
* AI conversations

This approach improves **knowledge retention and engagement.**

# 🧰 Technology Stack

## Frontend

* **React.js** – Component-based UI development

* **Tailwind CSS** – Utility-first styling framework
* **Motion UI** – Animation and transitions
* **React Bits** – UI component library
* **HTML5 & JavaScript**

* Firestore Database
